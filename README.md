Descripcion del proyecto:
Este sistema consiste en combinar 3 bases de datos para simular una aplicación de salud y bienestar, el integrar estas bases de datos nos da la ventaja de que se aprovechan al máximo cada una de estas.


Flujo de trabajo:
Los datos se van a insertar en el archivo desde el archivo de populate, las consultas se haran dependiendo la base de datos que sea y desde el main se ejecutara la funcion correspondiente, estas funciones dependen de la base de datos y se guardaran es sus respectivas carpetas.
